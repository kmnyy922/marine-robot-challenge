# 해양로봇챌린지 (9조)

해양로봇챌린지에 참가하며 작성한 아두이노 코드입니다. (2026년 8월)

## 구성
- `V12_S/V12_S.ino`: 대회용 로봇 제어 코드
  - RC-100 리모컨(DynamixelShield)으로 전진·후진·좌회전·우회전
  - 16번 버튼: 초음파 센서로 장애물 거리를 재고 서보 모터를 돌린 뒤 후진·재전진하는 자율 회피 모드
- `arithmetic/arithmetic.ino`: 아두이노 함수 연습 (사칙연산 결과 시리얼 출력)

## 사용 부품
- Arduino + DynamixelShield, RC-100 리모컨
- DC 모터 2개 (L1/L2, R1/R2 PWM 제어)
- 서보 모터 (9번 핀), 초음파 거리 센서 (A0 에코 / A1 트리거)
